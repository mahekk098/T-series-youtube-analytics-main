# T-Series | YouTube Channel Intelligence Dashboard

A comprehensive YouTube channel analytics project focused on analyzing the content performance, audience engagement, and publishing patterns of **T-Series**.

This project uses **Python for data cleaning and transformation** and **Microsoft Power BI for interactive data visualization and dashboard development**.

---

## 📊 Project Overview

This project analyzes approximately **20K T-Series YouTube videos** to understand video performance, audience engagement, publishing patterns, and content trends.

The dashboard provides insights into:

- Video performance
- Audience engagement
- Monthly trends
- Publishing patterns
- High-performing videos
- Low-performing videos
- Engagement rate
- Video duration
- Publishing hour performance
